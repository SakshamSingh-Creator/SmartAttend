# ⏱️ SmartAttend

## Employee Attendance Management System

SmartAttend is a web-based Employee Attendance Management System developed using **Python, Streamlit, Pandas, Plotly and SQLite**.

The application helps organizations manage employee attendance, working hours and leave requests through separate Employee and HR dashboards.

## 🚀 Features

### 👤 Employee Features

- Employee Registration & Login
- Secure Password Hashing
- Daily Check-In / Check-Out
- Automatic Working Hours Calculation
- Attendance Status Tracking
- Late Check-In Detection
- Attendance History
- Personal Attendance Analytics
- Attendance Score Calculation
- CSV Attendance Report Download
- Leave Request Management

### 👔 HR Features

- HR Dashboard
- Employee Directory
- Complete Attendance Report
- Employee & Status Filters
- Working Hours Analytics
- Attendance Distribution Chart
- Smart Workforce Insights
- Top Attendance Performer Detection
- Late Check-In Analysis
- Leave Request Approval & Rejection
- CSV Attendance Report Download

## 🧠 Smart Analytics

SmartAttend includes workforce analytics to help HR understand employee attendance patterns.

The system provides:

- 📊 Overall Attendance Distribution
- 📈 Total Working Hours by Employee
- ⏰ Late Check-In Tracking
- 🏆 Top Attendance Performer
- 📉 Average Working Hours Analysis
